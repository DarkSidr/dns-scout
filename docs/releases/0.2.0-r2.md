DNS Scout 0.2.0-r2

Ручной выбор первого и второго резервного DNS, версия в LuCI/CLI, установщик с проверкой SHA256 и пакеты для пяти архитектур.

В этой сборке исправлено скрытие параметра «Всего DNS в цепочке» при ручном выборе: стили некоторых тем LuCI переопределяли стандартный атрибут hidden. В ручном режиме теперь показываются только выбранные резервы.

Проверено на BPI-R4 / OpenWrt 25.12.4. Настройки совместимы с 0.1.0 и 0.2.0-r1. Обновление не переключает DNS и не включает автовыбор.
