DNS Scout 0.2.0-r1

- Ручной выбор первого и второго резервного DNS. Сохранённый порядок применяется вместе с выбранным основным сервером.
- При автоматическом выборе основного DNS закреплённые резервные исключаются из кандидатов на основной. Неисправный резерв не заменяется молча другим провайдером.
- Номер версии отображается в LuCI, RPC и `dns-scout version`.
- Установщик автоматически выбирает APK/IPK и архитектуру, проверяет SHA256; поддерживает установку локального релиза.
- Исправлена преждевременная разблокировка кнопки запуска теста.
- Старые настройки совместимы: отсутствие новых полей означает прежний автоматический подбор резервов.

Пакеты: aarch64_cortex-a53, arm_cortex-a7_neon-vfpv4, mips_24kc, mipsel_24kc, x86_64.
Аппаратная проверка: BPI-R4, OpenWrt 25.12.4. Другие архитектуры кросс-компилированы; аппаратно не проверены.
Установка самого DNS Scout не применяет новый DNS и не включает автовыбор.
